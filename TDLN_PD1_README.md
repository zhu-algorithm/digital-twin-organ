# TDLN PD-1 response baseline

This branch adds a runnable, leakage-aware baseline for converting TDLN single-cell data into patient-level immune features and predicting binary anti-PD-1 response. It preserves the original organ visualisation on `main`.

## What was actually found

Repository history and all branches were checked. At reconstruction time the repository had only `main`; no TDLN/PD-1 training implementation or matching commit existed. The existing project contains organ visualisation, CELLxGENE-derived expression summaries, and attribution rows for immune-checkpoint datasets. Those rows are provenance, not a labelled TDLN response cohort. This implementation is consequently a new baseline, not a recovered validated clinical model.

## Pipeline

1. Load cell-level CSV or optional `.h5ad` (`obs.patient_id`, `obs.cell_type`), preserving tissue, clonotype, recognized temporal fields and any explicitly requested custom time field; both formats require an explicit baseline slice whenever temporal columns exist. AnnData cohorts with stable IDs in `var_names` must explicitly name their `var` gene-symbol column, and studies may explicitly select the normalized expression layer used for signatures.
2. Compute TDLN-restricted patient-level cell fractions and cytotoxic, exhaustion, interferon, Treg, TCF7-memory, and dendritic-activation signatures while retaining paired tissues for TCR sharing. TCR features use one fail-closed assignment filter and report unique-clone sharing, TDLN cell-weighted sharing and set Jaccard overlap; missing/unassigned placeholders can never count as shared lineages.
3. Join pre-specified binary patient labels.
4. Select logistic-regression regularization only inside nested, stratified patient-grouped cross-validation and generate one out-of-fold probability per patient.
5. Write cross-validated predictions, metrics, and a fitted model artifact.

The mechanistic digital-twin layer additionally simulates the tumour–blood–TDLN axis, antigen transport, DC migration, Tpex self-renewal/differentiation, effector export, exhaustion/reinvigoration, anti-PD-1 pharmacokinetics, TDLN exposure, and receptor occupancy. See [`docs/TDLN_MODEL_CARD.md`](docs/TDLN_MODEL_CARD.md) for evidence, verification and the validation ladder.

The zone-resolved layer is a directed reaction–transport network across afferent lymph, subcapsular sinus, paracortex, follicle, medulla and efferent lymph. It transports antigen, mature DCs, Tpex and effectors. The liver bridge now supplies separate calibratable afferent sources for soluble antigen and migratory mature DCs; sinus antigen capture creates an additional DC route, while the DC-only route cannot create soluble antigen. Priming/differentiation occurs in paracortex. `--transport-only` disables reactions for mass-conservation audits.

The six-zone network can consume the systemic model's time-varying PD-1 receptor occupancy. This makes treated and untreated spatial counterfactuals distinct while preserving exact zero-occupancy equivalence and transport-only mass conservation. Coupling gains remain calibration parameters rather than fitted clinical effects.

Paracortical Tpex priming and expansion share an explicit finite niche capacity. Production approaches zero at capacity, while differentiation, death and egress remain active, preventing indefinite antigen-driven exponential expansion. The capacity is serializable, calibratable and included in the default spatial sensitivity screen; its bundled value is a research prior rather than a measured human lymph-node limit.

Systemic-to-spatial coupling is fail-closed: every supplied timeline row must contain a numeric, finite, unique time and a complete finite receptor occupancy within `[0,1]`. Invalid rows are never dropped, and callable occupancy sources are rejected rather than clipped when they leave the physical range.

Grouping is performed at the patient level; cells from one patient never become independent train/test observations.

Single-cell expression columns preserve explicit missing values for downstream fold-internal imputation, while supplied non-numeric or infinite signature-gene values fail before aggregation. For `.h5ad`, `--gene-symbol-column` maps a declared `adata.var` column onto the marker panel and `--expression-layer` selects the exact `adata.layers` matrix; missing columns/layers, empty symbols and duplicate signature symbols fail closed. Only the small marker panel is materialized, including from sparse layers. These choices are replayed from the feature audit and must be identical in `qc` and `featurize`; no layer is guessed. By default, a configured signature is emitted only when at least 50% of its marker genes are present; otherwise its global and lineage-restricted values remain explicitly missing. A study may pre-register another threshold in `(0,1]` through the identical `--min-signature-gene-coverage` option on both `qc` and `featurize`. The selected threshold and exact per-signature coverage are written to `qc_` columns excluded from model fitting. Negative finite values remain valid because some normalized/scaled assays legitimately produce them. Cell-type fraction names use deterministic normalization, and distinct labels that collapse to the same feature name are rejected rather than overwriting one another; cohort-specific aliases should be harmonized upstream under a recorded ontology map.

Multiple baseline samples from one patient require an explicit `--sample-column`. Cell fractions and global/lineage signature means are first computed within each sample and then averaged equally across that patient's feature-compartment samples, so a deeply captured library cannot dominate merely by contributing more recovered cells. Recognized `sample_id` or `library_id` columns fail closed when no sample column is declared. Sample IDs must be complete and non-empty; the chosen column, equal-sample estimand and per-patient sample count are recorded in the derivation audit/QC fields. TCR repertoire summaries remain cell/rearrangement based over the selected patient material and therefore still require upstream repertoire depth and chain QC.

For byte-stable qualification on the supported Python 3.10/3.12 matrix, install with `python -m pip install -c constraints/py310-312.txt -e '.[test]'`. The constraint file pins the numerical and test stack, including transitive packages that can affect serialization or numerical behavior. `pyproject.toml` retains bounded compatibility ranges for library use, while CI runs the exact qualified stack and prints its versions. Updating the lock is a deliberate qualification event requiring the full two-interpreter workflow; a green test on an unpinned environment is useful compatibility evidence but not the same reproducibility claim.

For longitudinal paired-tissue data, use the same temporal and tissue selection for both gates, for example `tdln-pd1 qc ... --time-column timepoint --baseline-values baseline --feature-tissue-pattern 'tdln|lymph'` followed by the same selection in `tdln-pd1 featurize`. Expression features default to the TDLN/lymph-node compartment; `--feature-tissue-pattern all` is an explicit opt-out. Omitting the temporal selection when a recognized time column exists is an error, preventing post-treatment information from leaking into a baseline model. AnnData ingestion preserves these `obs` fields before applying exactly the same gate, including a custom field named by `--time-column`; it may not silently discard time metadata. Missing or empty patient/cell-type identifiers fail during loading in both formats. QC also fails if any patient lacks cells in the chosen feature compartment.

`featurize` reports both cohort-wide signature summaries and lineage-restricted cell-state summaries. Cytotoxic, exhaustion and TCF7-memory programmes are calculated within CD8/Tpex-like cells, the Treg programme within regulatory T cells, and dendritic activation within DC annotations. The mechanistic initializer prefers these lineage-restricted measurements and falls back to the legacy global summary only when the relevant lineage is absent. This reduces composition/state conflation, but annotation harmonisation and assay-specific normalization remain cohort responsibilities.

When clonotypes and tissue labels are present, TCR features separate pooled, TDLN-only and tumour-only richness, Simpson concentration, normalized entropy and top-clone fraction. Cross-tissue output includes clone-set overlap, sharing as a fraction of both TDLN and tumour clonotyped cells, and abundance-weighted Morisita–Horn overlap. The abundance-weighted statistic is less dominated by rare-clone discovery than Jaccard but remains sensitive to repertoire sampling, chain definition, productive-sequence filtering and unequal cell recovery; these remain upstream assay responsibilities.

Cell-type proportions are rendered as a complete patient-by-cell-type composition over the selected baseline feature compartment. If a cell type is observed elsewhere in the cohort but absent from one patient's selected cells, its fraction is an explicit zero and all fractions for that patient sum to one; it is never represented as missing and median-imputed. Expression signatures and clonotype summaries retain true missing values when the assay or required coverage is unavailable, preserving the distinction between biological absence and unavailable measurement.

For model development and locked external use, `--cell-type-vocabulary` freezes the annotation labels and therefore the fraction-column schema across cohorts. Every vocabulary member is emitted for every patient, including explicit zeros when absent; a selected-compartment annotation outside the vocabulary fails rather than creating an unreviewed feature. The ordered vocabulary is stored in the feature derivation audit and used during deterministic replay. Tumour cells used only for cross-tissue TCR sharing do not have to enter the TDLN composition vocabulary. Annotation harmonisation remains a scientific preprocessing responsibility—the option enforces a declared schema but cannot make incompatible annotations equivalent.

When no explicit vocabulary is supplied, the inferred vocabulary is built only from cells in the selected feature compartment, not from every tissue used for auxiliary TCR sharing. Tumour-only or malignant annotations therefore cannot create constant zero columns in a TDLN composition. This inferred mode is convenient for exploration; a locked explicit vocabulary remains recommended for development-to-external transfer.

`verify` is a fail-closed numerical qualification gate. It checks finite/non-negative systemic states, scaled zero-dose numerical equivalence, monotone default dose/occupancy direction, endpoint stability under tighter solver tolerances, per-species conservation in the reaction-free spatial network, high-antigen Tpex saturation at the finite niche capacity, and the prespecified checkpoint-coupling direction. The spatial layer additionally runs a fixed 0/0.25/0.5/1/2 dose series and requires zero-dose equivalence plus non-decreasing occupancy, efferent effectors and paracortical Tpex. It writes every measured error and tolerance to JSON and exits non-zero if any invariant fails. Zero-dose schedules restart the adaptive solver at event boundaries, so equivalence uses a documented state-scaled relative tolerance rather than a dimensionally invalid near-zero absolute tolerance. These are software and numerical checks, not biological validation or evidence for clinical dose escalation.

Both ODE layers inspect raw solver states before writing output. Only negative drift within a documented state-scaled `10 × (atol + rtol × scale)` numerical budget is clipped to zero; larger negative excursions, non-finite states, or material systemic receptor occupancy outside `[0,1]` abort the simulation. Output clipping therefore cannot conceal solver failure under extreme parameterizations.

The interactive six-zone virtual organ is published from [`docs/tdln.html`](docs/tdln.html). Its trajectories are not hand-authored: `python scripts/export_tdln_dashboard.py` deterministically exports the mechanistic and spatial simulations to a versioned local JSON file. CI regenerates the file and rejects stale dashboard data.

`spatial-featurize` is the explicit bridge from segmented spatial transcriptomics, imaging or deconvolution output into the executable six-zone model. Each input spot must carry a patient identifier, a curated anatomical `zone`, and non-negative `antigen`, `mature_dc`, `tpex` and `effector` abundance estimates; an optional area or cell-count weight converts densities into amounts. Unknown anatomy, duplicate spot identifiers, negative values and non-finite values fail closed. The command does not guess zones from coordinates, because coordinates without a tissue mask and landmarks do not identify lymph-node microanatomy. It emits an explicit 24-state grid for every patient: zones with source spots carry `zone_observed=true`, while absent zones are explicit zero-valued modelling assumptions with `zone_observed=false`. The simulator rejects partial long tables instead of silently creating their missing states. `simulate-spatial --initial-zones` then runs this auditable zone-resolved state rather than the population default. Abundances must be calibrated to consistent model units before patient interpretation.

Every `spatial-featurize` run also emits `<output>.spatial-audit.json`, binding the raw spot table, selected weight column, explicit time column/baseline values, curated-anatomy policy and explicit-missing-zone policy to the complete state CSV. `verify-spatial-features` independently re-hashes both sides and deterministically reruns baseline selection, weighting, zone completion and long-state rendering; a changed setting or non-reproducible output fails. Recognized spatial temporal columns require an explicit baseline selection, and every patient must retain baseline spots; post-treatment slices cannot be silently pooled into the initial condition. For example: `tdln-pd1 spatial-featurize --spots examples/spatial_spots_cohort.csv --weight-column area --time-column sampling_day --baseline-values 0 --output artifacts/spatial_cohort_initial.csv`. When supplied to `augment-twin`, the spatial audit is validated and its fingerprint joins the hybrid manifest beside the single-cell feature audit. This proves transformation integrity, not segmentation or deconvolution accuracy.

Adding `--dose-days` couples the systemic anti-PD-1 pharmacokinetic/receptor-occupancy trajectory into that measured spatial state. `--paired-counterfactual` runs control and treated arms from the exact same patient initialization and writes an explicit `arm` and time-varying `pd1_occupancy` on every spatial row. A zero-amount schedule is numerically equivalent to control, while the default positive schedule increases efferent effectors in the prespecified verification scenario. Dosing is rejected in transport-only mode because receptor occupancy acts on immune reactions, not conservative transport.

Systemic trajectories use right-continuous bolus semantics: the row at a dosing boundary is the post-dose state and `administered_dose` records the coalesced amount. A schedule at exactly the terminal simulation time fails instead of being accepted and silently ignored.

Install `.[single-cell,test]` to read `.h5ad` directly.

`qc` is the mandatory pre-training gate for imported cohorts. It checks cryptographic provenance, licensing/source metadata, patient matching, duplicate labels, binary outcomes, class balance, cell counts, per-signature marker-gene coverage and usability, paired TDLN–tumour samples and clonotype assignment. Sub-threshold signatures are listed as warnings and emitted as missing rather than silently estimated from an inadequate panel. The same pre-registered coverage value must be supplied to QC and featurization; both outputs record it for comparison. Invalid zero, above-one or non-finite thresholds fail closed. A failed gate exits non-zero so CI and workflow systems cannot silently continue.

QC also executes the same `aggregate_cells` transformation used by `featurize`, with the identical baseline and tissue-compartment arguments. Its report records whether feature derivation was validated and the resulting patient-row count. Invalid expression values, identifier failures, cell-type feature-name collisions or any other aggregation contract can therefore not pass QC and fail only later during feature construction.

Patient and outcome contracts are shared by training, site validation and locked external evaluation: identifiers must be present, non-empty and unique, while every response must be explicitly observed and equal to integer 0 or 1. Missing outcomes are never treated as a third class or silently removed.

## Interpretation and limitations

- The included demo is synthetic and proves software execution only.
- No clinical-performance claim is made. External cohorts, protocol harmonisation, class definitions, calibration, confidence intervals, and prospective validation are required before translational use.
- Small cohorts should report uncertainty and avoid feature/model selection outside nested cross-validation.
- Batch, cancer type, treatment regimen, sampling time, tissue site, and centre are likely confounders and should be added as cohort metadata when available.
- This software is research-only and is not a medical device.

## Patient/cohort data assimilation

Calibration observations use long format: `day,variable,value,sd`. Variables must be explicit simulator states or documented derived endpoints. Positive parameters are fitted in log space with uncertainty-weighted robust residuals. The output includes fitted parameters, residuals, weighted RMSE, Jacobian rank and condition number, parameters touching the search boundary, approximate local log-scale intervals and the complete fitted log-parameter covariance when estimable, an identifiability warning, and an AIC-like diagnostic. Optional `--profile-points` first establishes a separate Gaussian-error weighted-SSE optimum, then fixes each target parameter and re-optimizes all nuisance parameters with that same objective. The report distinguishes a resolved asymptotic 95% profile boundary from support that merely reaches the edge of the requested fold range; the Gaussian profile optimum is recorded separately from the primary robust estimate. The bundled observation file is synthetic and exists only to verify recovery of a known parameter.

`propagate-uncertainty` draws correlated fitted parameters from that saved multivariate log-scale covariance, keeps unfitted coordinates fixed, reruns the prescribed anti-PD-1 schedule, and reports the full sample table plus median and 95% percentile limits for tumour, Tpex, effector and target-occupancy endpoints. It fails if the fit is not locally identifiable or no covariance is estimable. `verify-uncertainty` binds the exact fitted parameter file, diagnostics, schedule, seed and sample count to both outputs. These intervals represent local asymptotic parameter uncertainty only; they exclude structural error, assay noise not represented in the fit, population shift and clinical uncertainty.

`propagate-spatial-uncertainty` applies the same correlated-covariance contract to an identifiable spatial fit. Every draw runs a zero-occupancy control and a dose-driven treated arm from the same selected measured 24-state initialization, reporting uncertainty in paracortical Tpex, efferent effectors and their within-draw PD-1 deltas. An empty or non-positive schedule is rejected rather than mislabeled as treated. The audit binds spatial diagnostics and parameters, optional fitted systemic parameters, exact initialization file and selected patient, dosing, seed and both result files. When the initialization came from `spatial-featurize`, its raw-spot derivation sidecar is also bound and rechecked; the same nested lineage now applies to spatial calibration and sensitivity audits. It is local parameter propagation, not a posterior predictive distribution or evidence for individual treatment benefit.

Calibration tables must be non-empty and contain one unambiguous observation per model coordinate (`day,variable` systemically and `day,species,zone` spatially). Repeated assays must be aggregated upstream under a declared measurement model rather than silently receiving extra optimizer weight. Log-space fit parameter names must be unique and their supplied base values finite and strictly positive; fixed parameters may still be zero when physically meaningful.

`calibrate-spatial` accepts longitudinal `day,species,zone,amount,sd` observations and fits only explicitly named positive `SpatialParameters` in log space. It can use a selected patient's measured zone initialization and an optional anti-PD-1 dose schedule, in which case the fixed systemic receptor-occupancy trajectory is coupled during every spatial fit evaluation. Reports use the same rank, condition, search-boundary and approximate local-interval diagnostics as the systemic layer, alongside observation-to-parameter sufficiency and an AIC-like score. The bundled spatial observations are synthetic and recover a known antigen-decay value; they are software verification, not biological calibration.

Fitted parameter JSON is executable rather than archival: `simulate --parameters`, `simulate-spatial --systemic-parameters/--spatial-parameters`, and `augment-twin --systemic-parameters/--spatial-parameters` load it with exact dataclass-schema and finite-positive-value checks. Whenever a parameter file is used, the command writes `<output>.parameters.json` containing its SHA-256 fingerprint and parameter class. Hybrid output also carries `qc_*_parameters_supplied` audit fields, which the model feature-role gate excludes from fitting. This closes the calibration-to-prediction chain and makes the actual parameterization independently checkable.

`augment-twin` also emits `<output>.twin-audit.json`, binding the source single-cell feature table, optional 24-state spatial initialization, fitted parameter files, all three diagnostic covariance files, simulation horizon, dose schedule, sample count and seed to the exact hybrid CSV. `verify-augmentation` requires every used input again, recreates correlated draws with the recorded deterministic streams, reruns every patient-level treated/control systemic and spatial simulation, and compares the canonical hybrid CSV. It is executed before training in CI and reports `derivation_replayed=true`. This enforces label-free deterministic transformation integrity but does not validate feature biology or counterfactual correctness.
When its feature input came from `augment_liver_tdln_counterfactual.py`, `augment-twin` recognizes that sidecar instead of treating the intermediate CSV as an opaque file. The complete liver-counterfactual payload—treatment manifest, fitted bridge parameters, covariance diagnostics, schedule contract and their hashes—is embedded beside the sidecar byte hash in the twin audit. Training then embeds that nested audit in the locked model artifact, preserving an inspectable lineage from regimen and assay inputs to predictions. Replacing either the sidecar or its embedded payload fails verification.

If that nested training lineage contains a treatment contract, locked `predict` fails closed unless the external feature table has its own matching `<features>.twin-audit.json`. The external audit must bind the exact feature bytes, attest label-free liver→TDLN augmentation, and carry the same `agent_class`, model dose scale and response definition as training. When training used a perfusion manifest, external data must additionally use the same dimensionless scale, measurement definition and normalization reference; cohort sizes and patient-level values may differ. Patient-specific schedules, regimen identifiers and measured flow multipliers are recorded because they are represented by the mechanistic covariates, while silently switching treatment endpoints or perfusion semantics, or supplying an unaudited CSV, is rejected before inference. This enforces semantic compatibility and file lineage, but does not prove that the external clinical endpoint or perfusion measurement was correctly adjudicated.
Training validates that manifest against the supplied hybrid table and embeds the manifest and its own SHA-256 in both metrics and the locked model artifact.

`featurize` emits `<output>.feature-audit.json`, binding the exact raw cell file, baseline values, temporal column, sample column/equal-sample estimand, tissue-selection pattern, AnnData gene-symbol column and expression layer, signature-coverage threshold and label-free declaration to the resulting patient feature CSV. `verify-features` independently re-hashes both sides and reruns cell loading, gene mapping/layer selection, baseline/tissue selection, sample-equal aggregation, marker coverage, lineage signatures, fractions and TCR summaries before comparing the canonical patient table. When this sidecar is present, `augment-twin` validates it and embeds its fingerprint in the augmentation manifest, extending the integrity chain from raw single-cell input through hybrid features and into the locked model. This detects file, setting or deterministic-transformation substitution; it does not authenticate the upstream assay or annotation process.

Each CLI calibration writes a cryptographic manifest binding the exact longitudinal observation file, fit fields, dose/profile settings and the fitted-parameter, diagnostic and residual outputs. Spatial calibration additionally binds the selected patient initialization and the default systemic parameter manifest used for dose-driven occupancy. `verify-calibration` requires the observation file again, plus `--initial-zones` when one was used, and fails if any bound input or output is missing or replaced. This proves file integrity, not parameter identifiability or biological validity.

`sensitivity` uses seeded Latin-hypercube sampling over log-scaled parameter ranges and ranks monotonic influence on final tumour cells, tumour effectors, TDLN Tpex and peak PD-1 occupancy using Spearman correlations. These are screening statistics, not Sobol variance-decomposition indices or causal effects. The full sampled design is saved so every ranking is reproducible and inspectable.

An explicitly supplied dose schedule is validated as a whole: non-finite, negative, endpoint or out-of-window events fail instead of being silently removed. Library callers that omit a schedule receive the standard days 0/14/28 regimen truncated prospectively to events strictly before their requested simulation endpoint.

The systemic screen can center its ranges on an exact fitted `TwinParameters` JSON. Its report directory includes a provenance record with the parameter-file SHA-256, complete sampling design configuration, and hashes of the exact sample and ranking tables. The audit verifier fails if either result table is subsequently replaced.

`spatial-sensitivity` applies the same seeded screening design to the six-zone model. Every parameter draw runs a matched zero-occupancy and prespecified-occupancy pair from the same initial state. Rankings cover untreated endpoints, occupied endpoints and the paired PD-1 effect on paracortical Tpex and efferent effectors. This separates general spatial dynamics from the model-implied checkpoint contrast, but remains a screening analysis rather than evidence of a clinical treatment effect.

With `--dose-days`, the occupied arm is instead driven by the complete time-varying receptor-occupancy trajectory from the systemic antibody model. `--systemic-parameters` can bind that trajectory to a fitted PK/occupancy parameter set. Without a dose schedule, the command deliberately retains the simpler fixed-occupancy experiment and labels the mode in both rankings and provenance.

Rank rows explicitly carry `estimable`. If an outcome is constant across the sampled design, the correlation is marked non-estimable with neutral numeric placeholders (`rho=0`, `p=1`) rather than emitting an undefined statistic or silently dropping the endpoint.

The spatial screen accepts both an exact fitted `SpatialParameters` JSON and one patient selected from a complete spatial-omics state table. Its provenance file binds the fitted-parameter hash, spatial-state file hash, selected patient, sampling ranges and random seed to cryptographic hashes of the generated samples and rankings. `verify-sensitivity` requires every non-default parameter or state file again and detects substitution of inputs as well as result tables.

## Mechanism–ML fusion

`augment-twin` maps each patient's measured dendritic, cytotoxic, exhaustion, TCF7-memory and immune-cell-fraction features to bounded initial states, runs matched untreated and anti-PD-1 counterfactuals, and appends mechanistic endpoints. These include receptor occupancy, Tpex/effector states and treated-minus-control tumour/effector effects. The mapping is explicit in `hybrid.py`; response labels are not accepted or used during augmentation. The resulting hybrid table can be supplied to the existing `train` command.

When both measured features and `twin_` mechanistic features are present, training emits a paired mechanism–data fusion ablation. Data-only, mechanism-only and hybrid logistic models use the exact same outer patient folds; each block repeats regularization selection only inside its corresponding training partition. The report gives each block's complete out-of-fold metrics and hybrid-minus-data-only changes in AUC and average precision, plus data-only-minus-hybrid improvements in Brier score and log loss. A deterministic 500-draw paired patient bootstrap supplies percentile intervals for all four differences, and the corresponding block probabilities are retained in `cv_predictions.csv`. The bootstrap resamples fixed paired out-of-fold predictions; it does not refit models or quantify fold-selection instability. This tests whether the mechanistic block adds signal on the development cohort without giving it a different split, but remains exploratory internal evidence and cannot establish causal or external clinical benefit.

The assay-to-state bridge is a strict `FeatureStateMapping` JSON rather than an untracked set of literals. It controls signature intercepts, lower/upper state multipliers and lineage-specific coefficients shared by the systemic and spatial initializers. `examples/feature_state_mapping.json` reproduces the historical defaults. A supplied mapping is schema-checked, fingerprinted in both parameter and augmentation sidecars, independently reverified before training in CI, and marked only through a model-excluded `qc_` field. These coefficients still require cohort-specific calibration against quantitative cell/state measurements; versioning them does not make their defaults biological measurements.

Locked inference emits prediction-audit schema version 3. External `evaluate` requires the exact `--model` and `--features` used by `predict`, verifies their fingerprints, reruns `predict_locked`, checks the complete prediction CSV and patient count, and records `prediction_derivation_replayed=true` in the metric report. Evaluation audit schema version 2 additionally records the fixed bootstrap design and binds the complete metric report. `verify-evaluation` repeats locked inference and recomputes every metric, calibration diagnostic, applicability analysis, centre table and deterministic bootstrap interval from the bound labels; the regenerated JSON must match the audited report exactly. A probability or metric file cannot therefore be evaluated under a valid-looking audit without reproducing it from the bound inputs. This is deterministic computational integrity, not proof that the cohort is independent or clinically representative.

The bridge can be fitted from long-form paired measurements (`patient_id,target,value,sd` plus the same patient feature columns) rather than edited by hand:

```bash
tdln-pd1 calibrate-feature-state-mapping --observations examples/feature_state_mapping_observations.csv --fit tcf7_coefficient --base-mapping examples/feature_state_mapping.json --output artifacts/mapping_calibration
tdln-pd1 verify-calibration --audit artifacts/mapping_calibration/mapping_calibration_provenance.json --observations examples/feature_state_mapping_observations.csv --base-mapping examples/feature_state_mapping.json
```

Supported quantitative targets span systemic DC, Tpex, tumour effector/exhausted, Treg states and spatial afferent antigen/DC plus paracortical Tpex/effector states. Fitting is positive log-space robust least squares with rank, condition-number, boundary and local covariance diagnostics. It fails on duplicate patient-target pairs, unknown targets, invalid uncertainty or unknown coefficients. The included table is synthetic truth for executable verification, not patient evidence.

When calibration diagnostics are supplied, `augment-twin` additionally propagates the saved local log-parameter covariance into patient-level tumour, effector, spatial-egress and Tpex endpoints. Each endpoint gains a median, 95% lower/upper bound and interval-width feature, allowing the predictor to distinguish effect size from mechanistic uncertainty without reading an outcome label. Systemic and spatial draws use separate deterministic random streams because no joint cross-layer covariance has been estimated; these are local asymptotic mechanism intervals, not clinical confidence intervals.

`--mapping-diagnostics` extends the same propagation to the calibrated assay-to-state bridge. Each draw remaps the patient's features into systemic and, when measured zone states are absent, spatial initial conditions before rerunning both counterfactual arms. Systemic, spatial and mapping draws use three deterministic but independent streams because their joint covariance is unknown; measured spatial initialization remains measured rather than being overwritten by mapping draws. The mapping diagnostics file is bound into the augmentation audit and must be supplied again to `verify-augmentation`.

Before any systemic, spatial or mapping covariance is sampled, the diagnostic `fit_parameters` centre must match the loaded parameter artifact for every fitted coordinate. A covariance file from a different fit therefore fails even when both files are independently well-formed and correctly hashed.

The label-free boundary is enforced before simulation on both inputs: patient feature tables and measured spatial-state tables reject response/responder, outcome, label, RECIST, PFS, progression-free and overall-survival-like column names. Outcomes therefore cannot be carried through the mechanistic transform as inert-looking columns even if a downstream caller bypasses the standard training command.

The same patient row now initializes the six-zone spatial twin: dendritic activation scales afferent DC input, TCF7-memory scales paracortical Tpex, cytotoxic/CD8 features scale paracortical effectors, and an optional `tumour_antigen_proxy` scales afferent antigen. When that proxy is absent the population default is retained rather than inferred from an unrelated expression signature. Treated/control efferent-effector endpoints and paracortical Tpex are appended to the hybrid feature table.

Optional absent/NaN mechanistic inputs use their documented defaults. A supplied measurement is never silently repaired: immune signatures must be finite and may be signed so centered/scaled assays remain compatible; their state multipliers are explicitly bounded. Antigen proxies must be finite and non-negative, cell fractions must lie in `[0,1]`, and non-numeric values fail before simulation. Assay-specific signature scaling still requires cohort calibration before biological interpretation.

When `--spatial-initial-zones` is supplied, `augment-twin` replaces that feature-derived spatial initialization with each patient's measured/deconvolved 24-state table. The spatial and single-cell patient sets must match exactly; missing or extra patients, incomplete or duplicate state coordinates, invalid anatomy, and any outcome column fail closed. Mechanistic spatial counterfactual endpoints then enter the same patient-level hybrid table used by `train`. `qc_spatial_initialization_measured` and `qc_spatial_zone_coverage` record the source and fraction of anatomically observed zones; both are excluded from fitting by the feature-role gate.

## Locked external evaluation

Training writes a versioned model artifact with its exact feature schema and decision threshold. `predict` applies that artifact without refitting, emits the locked threshold on every row and fails on missing features. `evaluate` requires one consistent valid threshold and uses it for all threshold-dependent metrics rather than silently reverting to 0.5. It reports ROC AUC, average precision, Brier score, log loss, balanced accuracy, sensitivity, specificity, calibration intercept/slope, calibration-in-the-large, an equal-frequency calibration curve and expected calibration error (ECE). The curve uses at most five bins and is explicitly descriptive for small cohorts. Patient- or centre-bootstrap intervals cover every scalar performance metric except the two logistic calibration coefficients, whose unstable small-sample resampling distribution is not presented as reliable. Raw probabilities must be finite and inside `[0,1]` before numerical clipping for logarithms; invalid model output is never silently repaired. A result is external validation only when the evaluation cohort was never used for model fitting, hyperparameter selection, threshold choice or feature design; running the command on the bundled synthetic cohort does not make it external evidence.

Training, prediction and evaluation normalize patient identifiers and fail closed on missing, duplicate or mismatched patient sets; no inner join may silently discard a patient. Model artifact version 9 stores SHA-256 hashes of normalized training identifiers plus a whole-cohort fingerprint. Locked prediction emits a per-patient overlap flag, and `evaluate` refuses the `external_locked_model` label if the artifact lacks this audit or any evaluation patient overlaps training. The hashes prevent accidental reuse; they are pseudonymous governance metadata, not anonymization against dictionary attacks on predictable identifiers.

The locked model matrix has the same measurement contract in training, site validation and external prediction: biological and mechanistic features must be numeric, and supplied values must be finite. Missing values remain explicit and are imputed by the training-fold or fitted-artifact median; positive or negative infinity and string placeholders fail before model execution rather than being silently coerced.

Patient identifiers alone are insufficient because a development cohort can be renamed. Version 9 therefore also hashes every locked-schema training feature vector independently of patient ID and stores a sorted whole-feature-cohort fingerprint. Prediction reports exact training-row reuse, and external evaluation fails if any row matches, even when all patient names differ. This detects exact reuse, not near-duplicate samples, shared biospecimens, batch leakage or related patients; those still require cohort governance and provenance review. Feature hashes are integrity metadata, not anonymization, and model artifacts remain governed cohort data.

Internal evaluation uses an outer patient-grouped fold for performance estimation and an inner patient-grouped fold to choose `C` from a fixed grid using log loss. If an outer training fold is too small to support two-class inner validation, it records an explicit fixed-`C` fallback instead of presenting it as tuned. The report includes the selected value and train/test size for every outer fold, a prespecified 0.1–0.9 decision curve, and an artifact-level final selection performed only after out-of-fold evaluation is complete.

Logistic likelihood is deliberately unweighted. Inverse-frequency class weighting would change the implicit response prior, so its raw score could not be interpreted as a probability for the observed development population without a separate prior correction. Artifact v9 records this probability estimand and the development response prevalence. This preserves the development sampling prevalence but does not make calibration transport when an external cohort has different prevalence, spectrum or case ascertainment.

Before any split, a label-blind role audit removes technical cell-count/QC columns such as `n_cells` and records why they were excluded. Non-numeric metadata must remain outside the model matrix. Outcome-like names (`response`, `outcome`, `RECIST`, survival labels, and related tokens) are rejected, as is any numeric feature that exactly copies or inverts the response vector. The included and excluded schema is persisted in both metrics and the locked artifact.

Artifact version 9 stores a deterministic patient-bootstrap refit ensemble. The primary locked probability is produced by the final model fitted to the complete development cohort at the selected `C`, and its decision threshold is applied to that same estimand. Bootstrap median, 2.5th/97.5th percentiles and interval width are reported separately and never replace the point estimate. The final `C` is held fixed across bootstrap members so the interval measures patient-resampling instability rather than mixing in an undocumented tuning procedure. A percentile interval need not contain the full-cohort point estimate because they are distinct estimands. This is model-resampling uncertainty only: it does not cover assay error, population shift, causal ambiguity or mechanistic structural uncertainty.

Locked prediction now requires artifact version 9, its explicit `full_cohort_locked_model` point-estimate contract and its preprocessing contracts. The exact cell-type vocabulary SHA-256 is carried through featurization and hybrid augmentation into the artifact; external prediction must supply the same constant fingerprint. For legacy or deliberately hand-authored tables without this QC field, v9 records a weaker fraction-column-schema fallback explicitly. External evaluation requires the same single prediction method on every row. Prediction audit schema version 3 binds the method and artifact version into the SHA-256 chain, so legacy bootstrap-median files or incompatible preprocessing cannot be silently relabelled as v9 predictions.

When training is invoked through the CLI, artifact version 9 also embeds the exact hybrid-feature CSV hash and, when present, its parameter-provenance sidecar and sidecar hash. This binds the fitted predictor to the calibrated systemic/spatial parameter fingerprints used to generate its mechanistic covariates rather than relying on a detached workflow log.

The artifact also freezes a label-free training applicability profile for every model feature (median, robust scale, finite range and missingness). Locked predictions report each patient's maximum robust distance, fraction of features outside the observed training range, missing-feature fraction and a prespecified domain-shift flag. External evaluation fails closed when this audit is absent and reports in-domain coverage. These diagnostics expose unsupported extrapolation; they do not demonstrate biological transportability or justify discarding difficult patients after outcomes are known.

External metrics always use the complete submitted cohort as the primary analysis, including domain-shifted patients. A separate, prespecified in-domain sensitivity analysis is emitted only when at least four in-domain patients remain and each response class has at least two; otherwise its status is `not_evaluable`. The report records its locked selection rule, coverage and explicitly secondary role. This prevents applicability filtering from silently improving the headline result after outcomes are inspected.

When labels contain `center`, the pooled primary result is accompanied by a descriptive centre-stratified table. Every centre remains listed with sample size, responder count and prevalence; full metrics are calculated only when both response classes occur, while single-class centres are explicitly `not_evaluable`. The range of AUC and Brier score across evaluable centres exposes heterogeneity but is not a replacement primary endpoint or evidence of transportability.

`site-cv` performs leave-one-center-out evaluation: each centre is predicted only by a model trained on all other centres. Within every training partition, regularization is selected by a second stratified patient-grouped cross-validation scored by log loss; the held-out centre never participates in that choice. Candidate grouped splits are inspected before fitting and the fold count is reduced until every training and validation partition contains both response classes. If no valid two-class split exists, a fixed-`C` fallback is recorded rather than described as tuned. The same validated-split rule protects outer and final-selection folds. A held-out centre containing only one response class is still predicted in full and retained in pooled proper-score and threshold analyses; only its centre-specific discrimination metrics are marked `not_evaluable`. A centre is skipped only when the complementary training partition has one class and therefore cannot fit the classifier. This avoids conditioning cohort inclusion on held-out outcomes. It is a stronger internal transportability check than random folds, but it is still not an independently collected external validation.

The CLI creates a cryptographic chain of custody for locked evaluation. `predict` writes `<predictions>.audit.json`, binding the SHA-256 of the versioned model artifact and input feature table to the exact prediction CSV. `evaluate` requires and verifies that sidecar before reading outcomes, embeds the model/feature audit hashes in the metrics, and writes `<metrics>.audit.json` binding the prediction audit, raw label file, analysis settings and exact metric report. Replacing predictions after inference therefore fails closed. These hashes establish file integrity and reproducibility only: they cannot prove that a cohort is genuinely independent or that the analysis was prospectively registered.

The Python 3.10/3.12 CI matrix executes the complete calibrated patient-spatial sensitivity path, including fitted systemic and spatial parameters, measured 24-state initialization, dose-driven occupancy and independent verification of both systemic and spatial sensitivity result hashes. This is an integration gate, not biological validation.
