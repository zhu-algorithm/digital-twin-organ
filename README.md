# Digital Twin Organ · 数字孪生器官

**线上站点 → https://zhu-algorithm.github.io/digital-twin-organ/**

把公开的单细胞转录组与多组学数据变成可运行的器官模型：肝脏、肠道、肾脏、血管的药物代谢模型，
以及一个会跳动的数字孪生心脏。每个器官分三层——**器官层**（生理动态）、**细胞层**（细胞类型组成，
来自真实单细胞测序）、**分子层**（药物代谢酶与转运体表达）。三层之间有因果连接：分子层的表达量
经标度换算成器官清除能力，直接决定器官层的药物浓度曲线。

## 心脏模型

- **电生理**：O'Hara-Rudy 2011 人类心室肌动作电位（41 个状态变量），右端项由 Myokit 参考文件
  机器生成，未手工转写方程；SciPy BDF 积分
- **血流动力学**：四腔时变弹性腔 + 体/肺循环三元素 Windkessel + 心肌内压迫的冠脉分支
- **节律**：由拟合的 RR 间期生成模型逐拍驱动

38 项验证中 23 项有文献范围，20 项在范围内：

| 量 | 模拟值 | 文献范围 |
|---|---:|---|
| 静息膜电位 | −88.0 mV | −90 … −85 |
| APD90 | 266.1 ms | 255 … 295（ORd 2011） |
| 射血分数 | 61.1 % | 52 … 72（ASE/EACVI 2015） |
| 舒张末容积 | 131.3 mL | 62 … 150 |
| 心输出量 | 5.18 L/min | 4 … 8 |
| 冠脉舒张期灌注占比 | 76.5 % | 65 … 90 |

超出范围的 3 项（长轴缩短率、左室舒张末壁厚、左室舒张末压）及其原因见站点页尾与
`METHODS_heart.md`。每搏输出量与前序 RR 间期的相关 r = 0.964——短 RR 截短舒张期、充盈不足、
下一搏输出量下降，这个耦合来自循环电路本身而非人为抖动。

## 重要声明

心率节律来自**公开数据库记录，不代表任何特定个体**；所有相关文件中
`is_user_personal_data = false`。

本项目是**机制可解释的研究用模拟器，不是经临床验证的预测工具，不可用于任何临床给药决策**。
已知局限逐条记录在 `METHODS_heart.md` 与各页面底部，包括：mRNA→酶活性外推偏差、

## TDLN / PD-1 应答基线

独立重建分支提供从 TDLN 单细胞表达到患者级免疫特征、分组交叉验证和 PD-1 二分类基线的可运行管线。
实际核查结果、数据契约、运行方法与临床适用边界见 [`TDLN_PD1_README.md`](TDLN_PD1_README.md)。
系统层的 Naive CD8 稳态、Tpex/耗竭细胞死亡、Treg 诱导/死亡，以及空间层的抗原半饱和常数均为显式参数；默认值仅用于保持参考轨迹，尚未构成生物学或临床标定。

空间组学入口对多切片采样实行显式契约：出现 `sample_id`、`library_id`、`slide_id` 或 `section_id` 时，必须通过 `--sample-column` 指定采样单位，并用 `--sample-aggregation equal_samples`（完整切片等权且未覆盖区按零处理）、`equal_observed_samples`（每区仅在实际覆盖它的切片间等权）或 `sum_samples`（声明为物理总量）选择估计目标。该选择会进入可重放审计，避免切片数量或视野缺失在不知情时改变患者信号。状态表同时保留每个患者—区域的 `sampling_units_observed`、`sampling_units_total` 与 `sampling_unit_coverage`；它们是采样支持度 QC，不是生物学置信度，也不参与动力学状态量。

当空间视野没有覆盖全部六个区域时，`augment-twin` 默认用同一患者的单细胞特征—状态映射补齐未观察区域，同时原样保留已观察区域；`--spatial-missing-zone-policy explicit_zero` 可运行“未观察即为零”的敏感性对照。策略及补齐比例进入输出 QC 和可重放审计，避免把缺失解剖区域静默解释为真实零生物量。

混合输出还携带空间融合契约的 SHA-256：它区分“纯单细胞先验”“实测空间状态+先验补齐”和显式零策略。训练生成的锁定模型会冻结该契约，外部预测若更换空间来源或补齐语义将直接失败，而不是在同名特征下静默漂移。

`augment-twin --days N` 现在保证系统肿瘤层与六区域空间层都在第 `N` 天取终点，不再把长程系统终点与隐藏的 14 天空间终点混在同一行。输出中的模拟契约 SHA-256 同时锁定系统/空间终点日、给药日、剂量和配对反事实设计，外部预测不能用不同时间语义生成同名特征。

另一个机制参数契约 SHA-256 覆盖系统免疫/药代参数、六区域空间参数、单细胞到状态的映射，以及实际传播的全部不确定性参数抽样。锁定模型因此会拒绝由不同校准结果、默认参数或抽样集合生成的同名机制特征。

当 `augment-twin` 的输入含有上游 `liver-counterfactual-audit` 时，所有训练、留中心验证和外部预测命令还要求 `--augmentation-liver-replay-manifest`。该 JSON 以 `features` 为必填键，并可列出 `treatment_manifest`、`perfusion_manifest`、桥接/系统/空间/状态映射的参数与诊断文件；相对路径按清单所在目录解析。验证器会先完整重跑肝肿瘤—TDLN 患者反事实，再重跑外层六区 TDLN 增强，任一嵌套层无法复现都会停止拟合或预测。

## 肝脏肿瘤虚拟器官

新增的肝脏肿瘤病理层把门静脉／肝动脉灌注、氧供、正常肝细胞、肿瘤活性边缘、缺氧核心和坏死区连接为可运行的机制模型，并导出到可播放的交互页面。模型入口、方程边界与验证说明见 [`docs/LIVER_TUMOR_MODEL_CARD.md`](docs/LIVER_TUMOR_MODEL_CARD.md)；这是研究原型，不是临床预测工具。
肝肿瘤与 TDLN 已通过显式桥接参数形成双向闭环：活肿瘤／坏死／缺氧驱动引流抗原与 DC 激活，TDLN 产生的效应细胞回流并作用于肿瘤边缘；网页可直接比较未治疗与抗 PD-1 轨迹。
纵向桥接校准器接受带测量误差的系统和六区空间观测，拟合引流／免疫杀伤参数并输出可辨识性诊断、残差与 SHA-256 审计清单；数据契约和运行命令见模型卡。
患者级运行器把标签无关的单细胞 DC、CD8/Tpex、细胞毒性与耗竭特征有界映射到引流、DC 产出和免疫杀伤参数，并输出完整系统／六区轨迹与特征回退审计。配对反事实从相同患者初态分别运行自然进展和患者治疗清单中的抗 PD-1 方案，报告机制处理效应，但不将其表述为临床应答概率；队列增强器读取经纵向观测校准并通过哈希核验的肝–TDLN 桥接参数，将这些效应及局部参数不确定性区间转换为可审计的 `liver_cf_*` 特征，并实际进入 PD-1 训练管线。
