这一页在测什么

食管的签名特征不是代谢，而是运输。这一页把三件事做成可核验的数字： （1）从该受试者自己的内切半径剖面上实测生理性狭窄的位置与口径； （2）在三维管壁上让蠕动波真的行进，并在浏览器里实测波峰速度； （3）把食管下段的门-体静脉吻合做出来 —— 这是门脉高压时食管静脉曲张的解剖基础， 也是本项目肝脏页的跨器官连接点。

受试者不是 s0688 以外的那一位。本项目的心脏、肝脏、肾脏、小肠四页都用 TotalSegmentator 受试者 s0236。食管页没有沿用它：s0236 的扫描视野是腹部， trachea、thyroid_gland 以及全部颈椎与上胸椎标签为空， esophagus 标签只有 4443 体素（15.00 mL），仅覆盖远段。它在本器官自己的六条 筛选标准下直接不及格。因此本页改用 s0688， 跨器官解剖一致性在食管–胃交界处并不成立，这一点写进了 GEOMETRY_PROVENANCE.md。

四层管壁 —— 外膜，不是浆膜

层内容厚度（已发表）
两个必须记住的对比。其一，上皮是非角化复层鳞状上皮，而胃、小肠、结肠都是单层柱状上皮； 两者在胃食管交界处以 Z 线突变交接。其二，胸段与颈段食管的外覆是外膜（adventitia）， 没有浆膜、没有间皮。这是外科学上的关键差异：食管吻合口漏发生率高于胃肠吻合、 肿瘤早期即可达食管周围组织、T 分期里没有"穿透浆膜"这一级 —— 都源于此。 只有腹段食管前面覆有腹膜。

门-体静脉吻合与栅栏区

食管下段黏膜下静脉丛是门静脉系（胃左静脉 → 门静脉）与体循环系（奇静脉 → 上腔静脉） 的分水岭。正常时该丛向下引流入胃左静脉；门脉压超过体循环静脉压时胃左静脉血流反向（离肝）， 经栅栏区纵行通道向上减压入奇静脉，通道随之扩张为食管静脉曲张。 页面上的"门脉高压"开关切换的是两套预先烘焙的路径，不是压力–流量网络求解； 栅栏区流速 8 mm/s 是声明值，未检索到已发表的栅栏区流速。

药理学定位 —— 诚实版本

食管不是药物吸收部位。正常传输只有几秒，表面积约 0.02 m²（小肠约 200 m²）， 上皮是多层鳞状。本项目的四种探针药（咪达唑仑 / CYP3A4、右美沙芬 / CYP2D6、 二甲双胍 / OCT2-MATE、非索非那定 / P-gp-OATP）在食管没有任何 ADME 环节。 本页不画吸收箭头、不报通量、不使用任何标定系数。

食管真正的药理学意义是药物性食管炎：药片滞留后在无黏液毯保护的鳞状上皮上释放出高局部浓度。 滞留最常发生在本页实测到的那几个狭窄处和心后压迹处。
