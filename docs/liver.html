解剖剖面 — 肝小叶

六角形小叶：六个角是门管区（门静脉小支、肝动脉小支、胆管三联），中心是中央静脉。 血液由门管区流向中心，胆汁在毛细胆管内反向流回门管区——这个逆流结构是肝脏的关键解剖特征。

读图说明。器官层的血流量不是编的：总肝血流由本项目心脏模型实算的心输出量 （ L/min）乘以肝脏所占比例得到，但那个比例（约 25%）与门静脉/肝动脉的分流比（约 75:25） 是教科书量级值，不是本项目实测——页面上的每个数字都在下表标了出处等级。 呼吸位移的频率来自真实拟合（RSA 0.18323 Hz），但位移幅度（1–3 cm）是教科书范围。 小叶剖面的分区着色与下方表格用的是实测单细胞表达：图谱把肝细胞按小叶位置注释成三种独立细胞类型 （门脉周围 57,004 个细胞、中间带 19,907、中央静脉周围 26,491，均来自 24 位 donor），所以梯度可以直接读出， 不需要推断。梯度并非对所有基因一致：CYP3A4 中央静脉周围／门脉周围 = 1.37×，CYP1A2 = 2.21×， 而 CYP2D6 = 0.74×（方向相反）、CYP2C9 = 1.04×（基本持平）。这与已知的 CYP 区域异质性相符。

这一页不做什么。没有肝清除率计算，没有药物动力学求解——药物浓度沿窦状隙的递减是按分区表达加权的 示意，不是 well-stirred 或 dispersion 模型的解。把表达量换算成清除能力需要绝对丰度标定与 IVIVE 外推， 这一层尚未建立，所以此处只呈现定性趋势，不给定量预测。

数据来源声明。单细胞表达来自 CELLxGENE Census 2025-11-08（人类正常肝脏，10x 系列，is_primary_data=True， 2 个数据集 / 126,310 个细胞 / 11 种细胞类型）。呼吸频率导出自 PhysioNet MIT-BIH Normal Sinus Rhythm Database 记录 16265，为公开数据占位，不代表任何特定个体（is_user_personal_data=false）。 本项目为研究用模拟器，不可用于任何临床给药决策。
