几何来源与许可

TotalSegmentator 数据集 v2.0.1（117 种解剖结构 / 1228 例 CT）， DOI 10.5281/zenodo.10047292， CC-BY-4.0，署名类许可、可在公开仓再分发。使用受试者 s0236 （腹部 CT，1.5 mm 各向同性）——与本项目肝脏同一受试者，以保证跨器官解剖一致， 但按肾脏自己的标准重新核验过：筛查 18 例，2 例通过。 结构：kidney_left、kidney_right、aorta、 inferior_vena_cava、urinary_bladder、kidney_cyst_*。 只用 HTTP Range 请求从 23.5 GB 的 Zenodo 压缩包里取出这 7 个掩膜，不下载 CT 影像本体， 本项目不含任何基于影像灰度的内容。

实测：左肾 174.8 mL / 11.80 cm， 右肾 194.1 mL / 12.59 cm （成人参考体积 110–200 mL、长径 9–13 cm，两侧均落在范围内）。 两侧均为单连通分量、无视野截断、囊肿体积 0 mL。 注意：本例右肾大于左肾，与"左肾通常略大"的人群趋势相反，照实报告。 肾门凹陷深度 左 49.9 mm / 右 45.8 mm， 肾窦体积 左 37.9 mL / 右 43.1 mL， 二者都是在标签上量出来的（逐冠状层凸包亏损），不是假设的。 三角面合计 153,580，glb 4.99 MB。

皮质–髓质分层：构造的，不是分割出来的

源数据每侧肾脏只有一个标签，所以皮髓分界无法从分割里读出。这里的做法是： 以外层包膜（朝向肾窦的那一面不算在内，否则肾乳头这一全器官最深的结构会被判成皮质） 为基准做距离场，把公开成人皮质厚度 8.0 mm （文献 6–10 mm 的中点，非本受试者实测）之内定为皮质； 更深的实质按肾乳头做 Voronoi 划分成锥体，相邻锥体之间留出声明宽度 1.6 mm（半宽）的隔，这些隔就是Bertin 肾柱。

由此算出来（不是设定的）：每侧 10 个肾锥体（人类参考 8–18）， 锥体高 14.1–23.4 mm， 乳头间距 20.5–26.5 mm， 前排 3 个 / 后排 7 个 （前后两排是采样结果，不是强加的）。 皮质 左 135.7 / 右 148.7 mL， 髓质 左 39.1 / 右 45.4 mL， 肾柱 左 14.1 / 右 14.0 mL。 皮质体积占比 左 0.776 / 右 0.766， 落在已发表的 0.60–0.80 区间内。

动脉级联与肾脏的签名结构

肾动脉开口放在该受试者真实主动脉表面上，肾静脉开口放在真实下腔静脉表面上； 其余走行全部构造。级联按解剖顺序建立： 肾动脉 → 段动脉（5 支：尖段、前上段、前下段、下段、后段）→ 叶间动脉（必须穿行 Bertin 肾柱） → 弓形动脉（在皮髓交界处沿锥体底弧行） → 小叶间/皮质放射动脉（CCO 生长）→ 入球小动脉 → 肾小球 → 出球小动脉。

两处刻意没有交给优化器：叶间动脉的走行按"穿过肾柱而不穿过锥体"去选， 实测穿入锥体的采样点 左 1 个 / 右 0 个； 弓形动脉直接构造成锥体底平面内的圆弧 （每侧 19 条弧，跨度 84.0–154.0°）， 因为"沿皮髓交界弧行"就是这条血管的定义，CCO 不会自己长成那样。

肾脏的签名：两套毛细血管床串联。 出球小动脉不汇入静脉，而是第二次分支——皮质肾单位分成管周毛细血管， 近髓肾单位分成直小血管（与髓袢并行，构成逆流倍增器）。 全身没有第二个器官把两套毛细血管床串在一条小动脉上。 夹在中间的出球小动脉口径小于入球小动脉 （0.013 mm vs 0.02 mm，均为公开值）， 按 Poiseuille 其阻力比为 5.6×—— 这正是肾小球毛细血管压能维持在 45.0–60.0 mmHg、 而一般体循环毛细血管只有 15.0–25.0 mmHg 的物理原因（比值 2.62×）。

Murray 定律与硬性不相交

半径按 r = r_term · n_downstream^(1/3) 结构性强制， 因此每个分叉上 r_parent³ = Σ r_child³ 精确成立。 逐分叉核验的最大相对残差：renal_artery 0.0 / renal_vein 0.0 / collecting_system 0.0 （分别核验 623 / 581 / 8 个分叉）。 肾小球单元不适用该检验：它的口径是逐级公开值而非 Murray 推导，报告里单列。

三棵树之间施加硬性净空约束并求解（不是靠调偏移量凑）：动脉树先作为参照固定， 集合系统与静脉树被推开，最后三棵一起松弛；锚点（主动脉/腔静脉开口、扣在真实肾乳头上的肾盏尖端、 膀胱端输尿管锚点）始终冻结。 实测最小表面间隙：动脉–静脉 -0.729 mm， 动脉–集合系统 0.25 mm， 静脉–集合系统 0.25 mm。 需要说明：真实肾内动静脉是相伴而行、相距几百微米的， 这里 1.0 mm 的净空是建模约束而非解剖事实。

尺度诚实性

人肾约有 10⁶ 个肾单位；本场景每侧只渲染数百个终末。 因此渲染树的终末口径 0.8216 mm 对应的是 皮质放射动脉层级，而不是入球小动脉—— 主干锚定在公开肾动脉口径时，几百个终末的立方律级联到不了小动脉口径， 而本项目没有为了凑数去发明任何系数。 每个渲染终末代表约 3,130 个真实肾单位。 肾小球/球后单元共渲染 128 个，按公开小动脉与毛细血管口径绘制， 并在器官视图中以声明的 9.0× 口径放大显示（位置与长度仍为真值）。

血流动力学：与心脏模型耦合

肾血流由本项目心脏模型实算的心输出量推出： CO 5.1771 L/min × 肾分数 0.22 （教科书 20–25%，非实测）= RBF 1139.0 mL/min； RPF = RBF ×(1−Hct 0.45) = 626.4 mL/min （参考 600–700，落在范围内）； GFR = RPF × FF 0.2 = 125.3 mL/min。 后者落在经典教科书的 125 mL/min 上，而不在临床 eGFR 的 90–120 区间内， 按算出来的报，没有为了落进区间而调参。 平均动脉压 94.4872 mmHg 同样来自心脏模型。 净滤过压 = P_glomerular(52.5) - P_Bowman(12.5) - pi_plasma(28.5) = 11.5 mmHg。

搏动性直接用心脏模型自己的主动脉压波形（40 拍平均） 通过阻性耦合驱动。该耦合没有惯性项也没有动脉顺应性， 所以收缩期峰值被系统性低估：模型阻力指数 0.362， 公开参考 0.5–0.7，未达到；下表中动脉各级的峰值流速都继承了这一低估， 没有施加任何增益去掩盖。

自身调节

做了，但是现象学曲线而不是方程：它复现"灌注压 80–180 mmHg 之间肾血流与 GFR 近似恒定" 这一已发表观察。肌源性反应与管球反馈（经致密斑）在界面上只是标签， 本项目没有求解任何肌源性张力方程，也没有求解致密斑反馈动力学。

剖面视图：真实比例的肾单位

按真实毫米尺寸建模后以声明的 20.0× 显示。 皮质肾单位与近髓肾单位都做了，因为它们不是同一个东西： 皮质肾单位（约 85%）髓袢短、只略进入外髓、没有直小血管； 近髓肾单位（约 15%）肾小球位于皮髓交界、髓袢深入约 18 mm、并行直小血管。 近曲小管的 14 mm 是真实弧长盘绕在一个一毫米出头的皮质球内—— 这正是 40 mm 长的肾单位能装进 8 mm 皮质的原因。 致密斑（管球反馈的位置）画在升支粗段与自身肾小球的接触点上。 小管液流速同样是 v = Q/A，流量从本模型自己的单肾单位 GFR 出发， 按 kidney_model.json 中标明为教科书值的各段重吸收比例逐段递减。

没有做的：足细胞足突（0.2–0.4 µm）、裂孔隔膜、近端小管刷状缘微绒毛。 它们比 CT 分辨率低两个数量级、比本几何的来源低三个数量级，画出来就是插画而不是数据。 分子视图里的刷状缘环是声明过的示意。

分子层：二甲双胍的肾排泄通路

数据为本项目自建的肾脏单细胞 ADME 矩阵： 90 种细胞类型 × 61 个基因， 446,561 个细胞，CP10K + log1p。 近端小管上皮 113,966 个细胞 / 137 位 donor。

二甲双胍全程以原形排泄，不经任何 CYP 代谢，而且主要靠主动分泌而不只是滤过： 血液 →（基底侧）OCT2 SLC22A2 摄入 → 近端小管细胞 → （顶侧）MATE1 SLC47A1 / MATE2-K SLC47A2 外排 → 管腔 → 尿。 膜面是会画错的东西：基底侧对着管周毛细血管（血），顶侧带刷状缘对着管腔（尿）， 画反方向就反了，所以场景里每个转运体的位置都由数据中的 membrane 字段决定。
